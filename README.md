## claudecodellm

文件结构

```
litellm/
├── .env               # API Key 配置（不要提交到 Git）
├── config.yaml        # 多模型映射配置
└── docker-compose.yml # 一键部署
```

### 使用
```bash
git clone https://github.com/mazezen/litellm.git
```

### 步骤

1. 创建 .env（填入你的 API Key）

2. 创建 config.yaml（多模型映射）

3. 创建 docker-compose.yml
